# 🌌 Outlander

**Outlander** is a single-player, first-person 3D shooter built in **Unity** using **C#**, developed for the **Windows** platform. The game combines survival, combat, crafting, and resource management in a hostile alien environment, wrapped in a distinct low-poly, cel-shaded art style.

## 🚀 Game Overview

You play as an astronaut stranded on a toxic, uncharted planet after an emergency crash landing. Your primary mission: **repair your damaged spaceship engine** and escape before the planet’s deadly storms and aggressive fauna consume you. You'll need to gather resources, fight off dangerous alien creatures, manage your limited inventory, and make strategic decisions under pressure.

## 🎮 Core Features

- **First-Person Shooter Mechanics**: Tight shooting system.
- **Resource Collection & Crafting**: Extract materials from the environment and fallen enemies to build tools and essential equipment.
- **Inventory Management**: Limited storage capacity challenges players to make tactical choices during exploration.
- **Dynamic Storm Events**: Procedural storm system that affects enemy spawn rates and player decision-making.
- **Enemy Variety**: From fast swarming spiders to powerful ranged beetles, each enemy type requires different strategies.
- **Minimalist GUI**: Immersive interface providing critical info (health, dome integrity) without clutter.
- **Narrative & Progression**: Time-limited survival pressure due to degrading dome and resource scarcity.
- **Social Integration**: Optional Twitter sharing and Discord Rich Presence support.

## 📦 Installation & Running

1. Clone the repository:
   ```
   git clone https://github.com/Khevynn/outlander.git
   ```

2. Open the project in Unity (tested on Unity `2022.x.x` or newer).

3. Build the game:
   - Go to `File > Build Settings`
   - Select `PC, Mac & Linux Standalone` (Windows)
   - Click `Build`

> _Recommended: Use a system with a DirectX 11 compatible GPU._
